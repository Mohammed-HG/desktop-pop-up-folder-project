# Desktop Pop-up folder · Linux 1.4

[صفحة تحميل حزم لينكس](https://github.com/Mohammed-HG/desktop-pop-up-folder-project/releases/tag/linux-v1.4)

| التوزيعة أو طريقة التشغيل | الحزمة | الأمر |
| --- | --- | --- |
| Debian وUbuntu والتوزيعات المبنية عليهما | `desktop-popup-folder_1.4_all.deb` | `sudo apt install ./desktop-popup-folder_1.4_all.deb` |
| Fedora والتوزيعات المتوافقة مع حزمها | `desktop-popup-folder-1.4-1.noarch.rpm` | `sudo dnf install ./desktop-popup-folder-1.4-1.noarch.rpm` |
| Arch أو openSUSE أو توزيعات أخرى | `desktop-popup-folder-linux-1.4-portable.tar.gz` | فك الضغط، ثم شغّل `./run.sh` من المجلد الناتج |
| تشغيل ملف واحد | `desktop-popup-folder-linux-1.4.jar` | `java -jar desktop-popup-folder-linux-1.4.jar` |

تحتوي الصيغ الأربع على نفس التطبيق. حزم التثبيت تضيفه لقائمة التطبيقات وتحل اعتماديات التوزيعة. الحزمة المحمولة وملف JAR يحتاجان Java 17 أو أحدث بدعم الواجهة الرسومية، و`xdg-open` للملفات، و`gio` لتشغيل اختصارات التطبيقات. اترك ملف JAR أو المجلد المحمول في مكان ثابت؛ استخدم **Repair shortcut** بعد نقله.

أنشئ مجلدًا عبر **New folder**. محرر الإنشاء يعرض معاينة مباشرة، ويدعم اختيار اللون والرمز وإضافة الاختصارات وضبط حجم الشبكة قبل إنشاء المجلد. في المجلدات الموجودة وفي الإعدادات العامة يُحفظ التغيير تلقائيًا، و**OK** للإغلاق. افتح اختصار المجلد من سطح المكتب. بعض الواجهات تحتاج تفعيل أيقونات سطح المكتب أو السماح بتشغيل الاختصار. اسحب ملفًا أو اختصارًا إلى المجلد أو استخدم Ctrl+V لنقله إليه. اسحب ملفًا مخزنًا إلى سطح المكتب أو مستكشف الملفات لإخراجه إذا كان مدير الملفات يدعم النقل. **Add link** يضيف مرجعًا للملف من موقعه الحالي.

توجد البيانات في `$XDG_DATA_HOME/desktop-popup-folder` أو `~/.local/share/desktop-popup-folder` افتراضيًا. اختر العربية أو الإنجليزية، والمظهر الفاتح أو الداكن أو مظهر النظام من ترس الإعدادات في النافذة الرئيسية. اختر المجلد ثم اضغط أيقونة القلم لتعديل الاختصارات والحجم والأعمدة والشفافية. داخل المجلد تظهر علامة الإغلاق فقط. الشفافية تتطلب دعم مدير النوافذ. استخدم القائمة السياقية لإعادة ترتيب العناصر أو إزالتها من العرض. Windows Hello خاص بويندوز. يدعم إصدار لينكس ألوان المجلد ورموزها ومعاينتها. ثبّت librsvg2-bin على Mint لعرض أيقونات SVG المحلية إن لم تكن الأداة متوفرة.

## البناء

من جذر المستودع شغّل `sh Linux/build.sh` باستخدام JDK 17 أو أحدث وأدوات `dpkg-deb` و`rpmbuild` و`tar`. لبناء صيغة واحدة أضف `--jar` أو `--deb` أو `--rpm` أو `--portable`. أضف `--reuse-jar` لتغليف ملف JAR الموجود في `Linux/artifacts`. يجري اختبار التخزين والاختصارات والنقل قبل التغليف.
