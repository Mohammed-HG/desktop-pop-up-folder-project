# Desktop Pop-up folder · Linux 1.2

هذه نسخة لينكس مستقلة ضمن نفس المستودع. تحتوي الحزمتان على نفس تطبيق Java.

## التثبيت والتشغيل

- على Debian أو Ubuntu شغّل `sudo apt install ./desktop-popup-folder_1.2_all.deb` ثم افتح **Desktop Pop-up folder** من قائمة التطبيقات.
- على توزيعات لينكس الأخرى، ثبّت Java 17 أو أحدث، ثم شغّل `java -jar desktop-popup-folder-linux-1.2.jar`. اترك ملف JAR في مكان ثابت حتى تظل اختصارات سطح المكتب صالحة. يستخدم التطبيق `xdg-open` للملفات و`gio launch` لاختصارات التطبيقات.

أنشئ مجلدًا عبر **New folder**. افتح اختصاره من سطح المكتب أو اختر **Open** داخل التطبيق. بعض واجهات لينكس تحتاج إلى تفعيل أيقونات سطح المكتب أو السماح بتشغيل ملف الاختصار. استخدم **Repair shortcut** بعد نقل ملف JAR.

اسحب ملفًا أو اختصار تطبيق إلى المجلد، أو استخدم Ctrl+V، لنقله إلى تخزين المجلد. اسحب ملفًا مخزنًا منه إلى سطح المكتب أو مستكشف الملفات لإخراجه. يعتمد الإسقاط على دعم مدير الملفات لعملية النقل. **Add link** يضيف مرجعًا لملف في موقعه الحالي. تظهر الملفات المخزنة تحت `$XDG_DATA_HOME/desktop-popup-folder`، والافتراضي `~/.local/share/desktop-popup-folder`.

نسخة لينكس تستخدم واجهة Java Swing بالإنجليزية وتغطي المجلدات والاختصارات والنقل. ميزات Windows Hello وتخصيص ألوان وشارات الأيقونات الخاصة بإصدار ويندوز خارج نطاق إصدار لينكس 1.2.

## البناء

استخدم JDK 17 أو أحدث وأداة `dpkg-deb` على Debian أو Ubuntu، ثم شغّل `sh linux/build.sh` من جذر المشروع. ستظهر الصيغتان في `artifacts/linux`. يشغّل السكربت اختبارات حفظ البيانات وإنشاء الاختصارات والنقل قبل إنشاء الحزمة.
